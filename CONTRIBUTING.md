# Contributing to DialDeck

DialDeck is currently in the planning and hardware-verification stage. There is no application build or test suite yet.

For hardware reports, include the keypad's button/dial count, USB vendor and product IDs, macOS version, and a concise description of observed behavior. Remove serial numbers, account names, local file paths, and unrelated device information from logs.

Discuss substantial scope or architecture changes in an issue first. Keep pull requests focused and distinguish observed behavior from assumptions. When implementation begins, include relevant validation and document anything that could not be tested on hardware.

Contribute original work or appropriately licensed material with attribution. Do not submit proprietary vendor binaries, decompiled source, secrets, or personal profile data.
